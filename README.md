# 📊 Análisis de Desempeño de Tiendas - Alura Store

## 🧠 Descripción del Proyecto

Este proyecto consistió en un análisis de datos de ventas de cuatro tiendas pertenecientes a la cadena **Alura Store**, con el objetivo de identificar cuál de ellas presenta el peor desempeño y debería ser vendida para dar paso a un nuevo emprendimiento del Sr. Juan.

Utilicé herramientas de análisis de datos en Python, como **Pandas** para el procesamiento de la información y **Matplotlib** para la visualización de resultados. El análisis incluyó ingresos totales, cantidades vendidas, reseñas de clientes y eficiencia logística.

---

## 🔍 Lo que hice

- **Cargué y limpié** los datos de ventas desde archivos CSV.
- **Analicé** métricas clave como:
  - Total de ingresos por tienda
  - Productos más y menos vendidos
  - Número de unidades vendidas
  - Envío promedio
  - Evaluaciones de los clientes
- **Visualicé los datos** mediante distintos tipos de gráficos:
  - Gráficos de barras comparativas entre tiendas
  - Gráficos de burbujas para relacionar cantidad, producto e ingresos
  - Gráficos circulares para mostrar participación de categorías

---

## 📌 Herramientas utilizadas

- Python 3.11.12 
- pandas
- matplotlib

---

## 📎 Conclusión

Este proyecto es una demostración práctica de cómo la ciencia de datos puede apoyar la **toma de decisiones estratégicas** en negocios a partir del análisis exploratorio de información.
